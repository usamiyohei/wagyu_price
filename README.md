# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？

- リモートリポジトリとはインターネット上にあるリポジトリ、
- ローカルリポジトリとは自分のPCで管理しているプロジェクトの履歴

## プッシュとマージの違いは何でしょうか？

- プッシュとはローカルリポジトリの変更をリモートリポジトリに送ること
- マージとは2つのブランチの内容を1つにまとめること

## コミットとプッシュの違い

- コミットとはローカルリポジトリに変更履歴を保存すること
- プッシュとはローカルリポジトリの変更をリモートリポジトリに送ること

## コミットのメッセージはどのように書いてあげるのが最適でしょうか？

- 何を変更したのかわかりやすく記載する

## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？

- ローカルでは開発者が統合できレビューなしでできるがプルリクエストでは、コードレビューがされる

## コンフリクトを起こしてしまった場合、どう対処すべきですか？

- ファイルを確認し、どちらを残すのか決め、修正後マージをする。
